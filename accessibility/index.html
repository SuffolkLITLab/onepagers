docassemble and the AssemblyLine tools help turn court forms into WCAG 2.1 AA–compliant guided interviews.

Accessible out of the box

WCAG 2.1 AA compliance is built into docassemble and the AssemblyLine tools, including the essentials:

Screen reader support

Optional built-in screen reader, plus ARIA attributes for assistive technologies.

Keyboard navigation

Supports navigation without a mouse throughout the interview.

Structured HTML

Semantic headings, labels, and other landmarks for assistive technology.

Helps catch accessibility problems

The AssemblyLine adds tools for checking interviews against WCAG guidelines and documented best practices.

Interview style checker

AssemblyLine flags clear WCAG failures and other issues.

Automated testing

AssemblyLine runs accessibility checks on every interview update.

Guidance for courts and interview authors

The Document Assembly Line website documents best practices so interview builders can create accessible interviews with confidence.
